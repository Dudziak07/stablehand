## Use it from the stablehand repo

1. From the stablehand checkout, run `uv run tools/install.py codex --scope workspace`.
2. Run `codex` (or `codex.cmd` on Windows) in the stablehand folder, or open the folder in VS Code with the Codex extension (`openai.chatgpt`).
3. When building for a repository outside `stablehand`, pass `--add-dir <target>` (or `-C <target>` for commands inside the target).
4. Ask for the skill or agent and name the target repo path in the request, for example: "Create a read-only review agent for `../shop-api`".

The workspace install links each skill into `.agents/skills/<id>` and copies each agent into `.codex/agents/<id>.toml` inside the stablehand checkout. Artifacts still go to the target repo, never into stablehand.

## Install

```bash
uv run tools/install.py codex                                  # user scope: ~/.agents/skills + ~/.codex/agents
uv run tools/install.py codex --scope project --project <repo> # <repo>/.agents/skills + <repo>/.codex/agents
```

Note on coexistence: `.agents/skills/` is shared with Antigravity and OpenCode (`shared/references/coexistence.md`). If you also install Antigravity or OpenCode in the same scope, keep `.agents/skills/` for Codex/portable skills and use `.agents/plugins/<p>/` (Antigravity) or `.opencode/skills/` (OpenCode) for their platform-specific variants.

## Models & Free tier

- Works on **ChatGPT Free** (`codex login`) for normal interactive use, linting, and lightweight verification within rolling 5-hour/weekly limits.
- For heavy headless eval batches (`codex exec`), you can also configure BYOK providers (`wire_api = "responses"`) in `~/.codex/config.toml` (for example OpenAI API, OpenRouter, or DeepSeek).

## Windows

- **PowerShell 5.1 shim:** global `pnpm` or `npm` installs create `codex.ps1`, which default Windows PowerShell execution policy blocks. Run `codex.cmd` instead, or allow local scripts once with `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` in Windows PowerShell (`powershell.exe`).
- **NTFS junctions vs copying:** `tools/install.py` defaults to directory junctions on Windows and honours `--copy` in every scope. Agent `.toml` files are always copied.
