# stablehand for Antigravity

**Status: [✅ implemented (evals: 3 runs)](evals/RESULTS.md).** Implements contracts 2026.11.1 (plugin manifest 2026.11.2). Platform review 2026-11-26 against App 2.38.0, IDE 2.8.0 (2.7.0 local), and CLI `agy` 1.5.17 (1.5.5 local); originally evaluated 2026-10-23 on `agy` 1.4.5 with Gemini 3.8 Flash. See [PORT-NOTES.md](PORT-NOTES.md) for mapping decisions and [evals/RESULTS.md](evals/RESULTS.md) for evaluation runs.

## Use it from the stablehand repo

1. Wire this checkout into the workspace:
   ```bash
   uv run tools/install.py antigravity --scope workspace
   ```
2. Open this folder in Antigravity.
3. Add the target repository to the workspace: in the IDE or App as a multi-root folder (`File -> Add Folder to Workspace...`); in the CLI with `agy --add-dir <target-path>`.
4. Ask the agent for what you need (e.g., "I need a skill for <target-path> that...").

## Layout (an Antigravity plugin)

```
platforms/antigravity/
├── plugin.json                       v1 manifest (with schema, logo, suggestedPrompts)
├── assets/logo.svg                   128x128 plugin icon
├── skills/<id>/SKILL.md              one per contract in contracts/skills/
├── skills/<id>/references/*.md       generated by tools/sync.py (per-skill mode)
├── skills/validating-artifacts/scripts/lint.py   generated by tools/sync.py
├── agents/<id>.md                    one per contract in contracts/agents/ (App/CLI/IDE)
├── PORT-NOTES.md
└── evals/                            the port's translation of evals/scenarios/
```

## Install

```bash
uv run tools/install.py antigravity --scope workspace   # this checkout: .agents/plugins/stablehand (main flow)
uv run tools/install.py antigravity                  # links into ~/.gemini/config/plugins/stablehand
uv run tools/install.py antigravity --scope project --project /path/to/repo   # .agents/plugins/stablehand
# or, with the CLI:
agy plugin install /path/to/stablehand/platforms/antigravity
agy plugin validate --strict .agents/plugins/stablehand
```

Skills are then available as `/stablehand:<skill>`.
