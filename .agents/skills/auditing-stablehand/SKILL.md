Keep stablehand's platform knowledge, linters, implementations, and synced copies accurate without inventing results or bypassing contracts.

Verify first that the current repository has top-level `contracts/` and `platforms/` directories. Stop if asked to build artifacts for a user's external project instead of auditing stablehand itself.

## Process

1. **Run the full self-check script:**
   Run `uv run .agents/skills/auditing-stablehand/scripts/self_check.py --help` on first use, then execute:
   `uv run .agents/skills/auditing-stablehand/scripts/self_check.py --strict`
   This checks generated copy sync, `tools/tests`, card age (`<= 90` days), artifact linting for every platform and this skill, contract parity, release version consistency across manifests/`README.md`/`CHANGELOG.md`, and native CLI validators (`agy` and `claude`, when installed).

2. **Verify platform cards against live sources** (when asked if stablehand is up to date or when a card is stale):
   - **Antigravity:** fetch `https://antigravity.google/llms.txt` and `.md` page mirrors (`customization-discovery.md`, `skills.md`, `rules.md`, `subagents.md`, `plugins.md`, `build-plugins.md`, `hooks.md`, `mcp.md`, `models.md`, `cli/headless.md`, `changelog.md`), plus `https://antigravity.google/schemas/v1/plugin.json`. Inspect local `agy --version`, `agy models`, and `agy -p "Reply OK." --output-format stream-json`.
   - **Claude Code:** check `code.claude.com/docs` and `anthropics/claude-code` `CHANGELOG.md`.
   - **OpenCode:** check `opencode.ai/docs`, `models.dev`, and `anomalyco/opencode` releases.
   Record exact versions checked and today's date (`Last verified: YYYY-MM-DD`) in each verified card under `shared/references/` and in `docs/sources.md`.

3. **Apply updates in stablehand order:**
   - Edit `shared/references/*.md` (never edit `GENERATED by tools/sync.py` copies directly).
   - Update `tools/lint.py` and add regression tests in `tools/tests/test_lint.py` for every new check.
   - Only edit `contracts/` when changing cross-platform behavior; bump CalVer (`YYYY.M.N`) in contracts, both plugin manifests, `README.md`, and `CHANGELOG.md` consistently.
   - Update `platforms/<p>/` skills, agents, `PORT-NOTES.md`, and `README.md`. Never fabricate eval metrics in `evals/RESULTS.md`—record only runs actually executed.
   - Refresh generated files with `uv run tools/sync.py`.

4. **Verify after final edits:**
   Re-run `uv run .agents/skills/auditing-stablehand/scripts/self_check.py --strict` and `uv run tools/lint.py --project .`, then inspect `git status` and `git diff --stat`.

## Done when
- [ ] `scripts/self_check.py` exits 0 with zero errors and zero warnings across all platforms
- [ ] `uv run tools/lint.py --project .` reports zero errors and zero cross-platform collisions
- [ ] Every modified card fact cites a live source and updated `Last verified` date
- [ ] No generated files were hand-edited and no eval results were fabricated
